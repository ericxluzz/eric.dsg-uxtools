# ERIC · Mensagens

| Tipo | Padrão | Exemplo |
| --- | --- | --- |
| Erro de campo | O que está errado + como acertar. Abaixo do campo, vermelho, ícone. | Informe um e-mail válido, como nome@amajari.rr.gov.br |
| Campo obrigatório | "Informe" / "Escolha" + o campo | Escolha o setor responsável |
| Erro do sistema | O que aconteceu + o que fazer. Nunca código técnico. | Não foi possível salvar. Verifique a conexão e tente de novo. |
| Confirmação destrutiva | Título em pergunta com o objeto + consequência + botão com o verbo | Remover a etapa Vistoria? As 3 situações dela também saem do fluxo. [Cancelar] [Remover etapa] |
| Sucesso (toast) | Objeto + resultado. Sem exclamação. | Frente enviada ao setor Iluminação Pública |
| Aviso de prazo | Estado + data | Vence hoje · Atrasada · venceu 29/10 |
| Vazio | O que não há + quando aparece | Nada aqui agora. Quando chegar algo nesta aba, aparece aqui. |
| Sem permissão | O que não pode + com quem falar | Você não tem acesso a esta área. Peça à administração do sistema. |
| Sem conexão | Situação + o que acontece com os dados | Sem internet. O que você preencher fica salvo e é enviado quando voltar. |
| Duplicidade | Fato + o que o sistema faz | Já existe 1 solicitação parecida a 40 m. Se for o mesmo problema, a Central junta as duas. |

Regras: frase normal, sem "Atenção:", sem "por favor" repetido, sem exclamação, sem culpar a pessoa ("você errou"). Botões nunca "Sim/Não/OK": sempre o verbo da ação. Cancelar à esquerda do primário.
